ConnectBot is a secure shell client for the Android platform. Its ultimate goal is to create a secure connection through which you can use a shell on a remote machine and transfer files back and forth to your phone.

# Development Team

The main developer is [Kenny Root](https://the-b.org/) with various contributions from the community.

All of us are on the <strong>#connectbot</strong> channel on [Libera.Chat](https://libera.chat/) if you have questions. You can join via Libera.Chat's [webchat](https://web.libera.chat/) system or your own IRC client.

If you're a developer, check out details about how the current codebase is designed.

## Getting Early Builds

ConnectBot is under active development. If you want to get an early build, you can join the open testing group (a.k.a., beta testers). You can also go to the next level and join the elite closed testing group (a.k.a., alpha testers).

### Beta Testers

To join the Beta Testing team, there is one step:

1. [Opt-in to ConnectBot testing](https://play.google.com/apps/testing/org.connectbot)

### Alpha Testers

To join the Alpha Testing Team, there are two steps:

1. [Opt-in to ConnectBot testing](https://play.google.com/apps/testing/org.connectbot)
2. [Join the Connectbot Alpha group](https://groups.google.com/g/connectbot-alpha)
