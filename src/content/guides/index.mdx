# Guides

Start with a working connection, then make terminal input comfortable. Guides include written instructions; some also have a demonstration and an interactive tour.

[Download ConnectBot](/download/). You'll need your own SSH server and account credentials.

## Get started

- [Add your first SSH host](./add-host/).
- [Connect to a Raspberry Pi](./raspberry-pi/).
- [Administer a remote Linux machine](./linux-server/).
- [Set up Mosh for changing networks](./mosh/).
- [Troubleshoot a connection](/bugs/#connection-help).

## SSH keys

### [Which key algorithm should I use, and what does biometric protection do?](./ssh-keys/)

Compare RSA, EC/ECDSA, Ed25519, and DSA. Learn how fingerprint-protected Android Keystore keys differ from passphrases and confirmation prompts.

## Keyboard

### [How do I set up a Terminal Keyboard?](./terminal-keyboard/)

Choose a shared layout or create your own in the web editor, then import it into ConnectBot.

### [How do I keep the special keys visible?](./special-keys/)

Keep Ctrl, Esc, arrows, and other terminal keys on screen, even when you are not touching the terminal.

## Connections

### [How do I add an SSH host?](./add-host/)

Save your connection details so your server is ready to open from the Host List.

### [How do local, remote, and dynamic port forwards differ?](./port-forwarding/)

Choose a tunnel type, check OpenSSH or Dropbear permissions, and troubleshoot listening ports, destination addresses, and SOCKS settings.

### [How do I automate my post-login routine?](./post-login-automation/)

Combine text matching, commands, special keys, waits, and port-forward controls into a repeatable startup sequence. Learn how to handle failures and take over manually.

## Appearance

### [How do I change terminal colors and font size?](./terminal-appearance/)

Create a reusable profile and give your terminal a comfortable, readable appearance.

## Security

### [How do I verify my ConnectBot installation?](./verify-installation/)

Check a Google Play or GitHub Releases installation against ConnectBot's public signing certificates, then optionally trace its code to a GitHub build.
