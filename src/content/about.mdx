# About ConnectBot

ConnectBot is an open-source SSH and Mosh client for Android, created and maintained by [Kenny Root](https://the-b.org/). Use it to access remote terminals, manage multiple sessions, and create secure SSH tunnels.

[Download ConnectBot](/download/) or [learn how to connect to your first server](/guides/add-host/).

## The developer behind ConnectBot

I’m Kenny Root, known as **kruton** on GitHub. I created ConnectBot on November 12, 2007, the day the first Android SDK was publicly released. I’ve kept the project going ever since.

Today, I’m ConnectBot’s solo developer. Much of the work happens in evenings and on weekends: fixing bugs, improving security, testing on Android devices, and reviewing contributions. Community contributors have helped shape ConnectBot along the way, and I’m grateful for their work.

ConnectBot is my main open-source focus. I also work on its terminal and SSH libraries so other applications can use the same building blocks.
